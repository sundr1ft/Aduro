Welcome. This is the first post.

## Why I built this

I wanted a blogging setup that I fully understand and control — no magic, no hidden
configuration, just Markdown files turned into HTML.

## What's in the box

- **Markdown** with YAML front matter
- **Handlebars** templates with partials
- **Live reload** dev server
- Clean, fast output you can host anywhere

```js
// Example code block
const greet = (name) => `Hello, ${name}!`;
```

That's it. No plugins, no themes to fight with.
